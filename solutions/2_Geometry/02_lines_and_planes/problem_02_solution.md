## Question

Given

$$
L:(x,y,z)=(2,-1,3)+t(1,2,-2).
$$

State a point on the line and its direction vector, check whether $P=(4,3,-1)$ lies on $L$, and find the point corresponding to $t=-1$.

## Solution

We read the base point and direction vector directly
from the parametric form $r(t) = r_0 + t d$,
test whether $P$ satisfies the parametric equations
for a single parameter $t$, and evaluate $r(-1)$.

### Point on the Line and Direction Vector

Comparing $L:(x,y,z)=(2,-1,3)+t(1,2,-2)$
with $(x,y,z) = x_0 + t d$:

- A point on the line is:

$$
P_0 = (2, -1, 3)
$$

- A direction vector of the line is:

$$
d = (1, 2, -2)
$$

### Checking Whether $P=(4,3,-1)$ Lies on $L$

Set $(x,y,z) = (4,3,-1)$ and solve for $t$
in each coordinate:

$$
\begin{cases}
4 = 2 + t \implies t = 2, \\
3 = -1 + 2t \implies 2t = 4 \implies t = 2, \\
-1 = 3 - 2t \implies -2t = -4 \implies t = 2.
\end{cases}
$$

Since $t = 2$ satisfies all three equations,
$P = (4, 3, -1)$ **lies on** the line $L$.

### Point Corresponding to $t=-1$

Substitute $t = -1$ into the equation of $L$:

$$
r(-1) = (2, -1, 3) + (-1)(1, 2, -2)
$$

$$
r(-1) = (2 - 1,\, -1 - 2,\, 3 + 2) = (1, -3, 5)
$$

Thus, the point corresponding to $t = -1$ is $(1, -3, 5)$.
